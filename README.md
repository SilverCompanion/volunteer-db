# 🤝 SilverCompanion / volunteer-db

> **志愿者数据库** — 登记和管理陪伴者与被陪伴者的信息

---

## 📋 这是什么？

本仓库是 SilverCompanion 项目的 **志愿者信息登记中心**。所有想成为陪伴者的人、以及需要陪伴的老人/家属，都通过 Issue 在此登记。

---

## 👥 三维度标签体系

每位登记人都会被标注三个维度的评估标签：

| 维度 | 含义 | 等级 |
|------|------|------|
| **H（健康）** | 身体健康状况 | H+（健康）/ H0（亚健康）/ H-（需要照护） |
| **E（经济）** | 经济状况 | E+（宽裕）/ E0（基本）/ E-（困难） |
| **F（家庭）** | 家庭结构 | F+（有家庭支持）/ F0（独居）/ F-（完全无依靠） |

---

## 📝 如何登记？

### 我想成为陪伴者

1. 点击 [New Issue](../../issues/new)
2. 填写以下信息：
   - **姓名/昵称**：
   - **所在城市**：
   - **可陪伴时间**（如：每周六下午、工作日晚上）：
   - **擅长领域**（聊天/陪诊/购物/阅读/其他）：
   - **健康状况**：H+ / H0 / H-

### 我需要陪伴 / 帮身边的老人登记

1. 点击 [New Issue](../../issues/new)
2. 填写以下信息：
   - **老人称呼**（爷爷/奶奶/叔叔/阿姨）：
   - **所在城市/社区**：
   - **健康状况**：H+ / H0 / H-
   - **经济状况**：E+ / E0 / E-
   - **家庭结构**：F+ / F0 / F-

## 🏛️ 核心原则

- **11条尊严铁律（D1-D11）** 是不可触碰的底线
- 所有登记信息仅用于项目匹配，绝不外泄
- 陪伴报酬：80-200 元人民币/次（根据苦难深度指数）
